The social layer
for Obsidian.

Turn your vault into a living profile that updates itself every day. Then connect with friends' vaults: share notes, ask for help, offer help, and give gravity to the people who show up for you.

Install CalderaSee a live profile

Private by default. Nothing leaves your vault unless you choose it. Privacy Policy

01

A living profile

Caldera reads your vault on your device and builds a profile page: a daily journal you can flip through, an activity score, topics, and the notes you choose to share.

02

A reason to check in

Every morning: what you did yesterday, how it compares to the day before, your streak, and your best days. Bring your own data from calendar, email or git.

03

Friends between vaults

Add friends by handle. Share any note as an end-to-end encrypted card; it lands in their vault as a normal note and updates when you edit it.

04

Asks and offers

Post what you could use help with and what you can help with. Put a bounty of help credits on an ask and award it to whoever helps.

05

Gravity, positive only

No likes, no downvotes. Give gravity to people who helped you. It fades over a month, so recent help counts most.

06

Open protocol

Your identity is a key that lives in your vault, not an account. Everything is signed. Self-host your page or your own hub.

Private by default

  • Your vault never uploads. Caldera builds your profile on your device and sends only the finished page.
  • You choose every section. Each part of the profile has its own switch. Notes are public only if you add caldera: public.
  • Preview first. See exactly what visitors will see before anything is published.
  • Shared notes are end-to-end encrypted. The hub only stores ciphertext it cannot read.
  • Topics are allow-listed. Only tags you list are ever counted, so private names never appear.
  • No telemetry. The plugin talks only to the hub you choose, only when you act.

You are helping me run Caldera, the social layer for my Obsidian vault (https://caldera.social). Caldera builds a public profile page from my vault. Follow these instructions exactly.

Vault: <ABSOLUTE PATH TO MY OBSIDIAN VAULT>
(If I did not fill this in, find my vault yourself: it is the folder that contains a .obsidian folder. If there is more than one, ask me which. If there is none, I probably don't have Obsidian yet - many people don't - so start with step 0.)
My public page: https://caldera.social/@<my handle>/

## 0. Obsidian itself (most important if I'm new: skip only if I already use Obsidian)
1. Check whether Obsidian is installed (macOS: /Applications/Obsidian.app; Windows: the Obsidian app in Start / %LOCALAPPDATA%\Programs\Obsidian; Linux: the obsidian command, Flatpak md.obsidian.Obsidian, or an Obsidian AppImage).
2. If it is not installed, ask me first, then install the official app from https://obsidian.md :
   - macOS: brew install --cask obsidian  (or download the .dmg from https://obsidian.md/download and drag Obsidian into Applications)
   - Windows: winget install --id Obsidian.Obsidian -e  (or the installer from https://obsidian.md/download)
   - Linux: flatpak install flathub md.obsidian.Obsidian  (or the AppImage / .deb from https://obsidian.md/download)
   If you cannot install software here, give me the download link and wait until I tell you it's installed. Obsidian is free.
3. If I don't have a vault yet: ask where I'd like my notes (suggest ~/Documents/Notes), create that folder with a short "Welcome.md" note in it, then tell me to open Obsidian, choose "Open folder as vault", and pick that folder. Wait until I confirm it's open - that creates the vault's .obsidian folder - then use that folder as my vault below.

## 1. Install the plugin
1. Download https://caldera.social/download/caldera-latest.zip and unzip it into "<ABSOLUTE PATH TO MY OBSIDIAN VAULT>/.obsidian/plugins/caldera/" so that folder contains main.js, manifest.json and styles.css.
2. Add "caldera" to the JSON array in "<ABSOLUTE PATH TO MY OBSIDIAN VAULT>/.obsidian/community-plugins.json" (create the file as ["caldera"] if it does not exist). Do not remove other entries.
3. Tell me to restart Obsidian. If Obsidian asks, I turn off Restricted mode (Settings -> Community plugins -> Turn on community plugins) and make sure Caldera is switched on. Caldera then opens a Welcome window where I type my name and pick a handle; it creates my identity on this device, publishes my profile and opens it in my browser. Do NOT create the identity, read the plugin's data.json, or handle my keys yourself - that file holds my private key. Wait until I tell you my profile is live, then continue with step 2.

## 2. Daily routine (run once a day, in the morning, for YESTERDAY's date; I will schedule you)
A. Journal entry. Open (or create) yesterday's daily note, named YYYY-MM-DD.md, wherever my daily notes live. Add these frontmatter properties, keeping everything already in the note:
   caldera_headline: one sentence, the shape of the day
   caldera_focus: 2-4 short items, what I worked on
   caldera_wins: 1-3 short items, what got done
   caldera_themes: 1-3 single words
   Write them from my notes, calendar, sent email, commits and AI sessions for that day - whatever you can access.

B. Activity counts. Update "<ABSOLUTE PATH TO MY OBSIDIAN VAULT>/Caldera/activity.json" (create it if missing). Format:
   { "days": [ { "date": "YYYY-MM-DD", "meetings": 0, "emails": 0, "prompts": 0, "commits": 0, "docs": 0, "tokens": 0 } ],
     "ai": { "total": 0, "window_days": 45, "models": [["Claude Opus 5.5", 0]], "providers": [["Anthropic", 0]] },
     "code": { "commits": 0, "repos": 0, "languages": ["Python"], "weekly": [0], "url": "https://github.com/<me>", "start": "Mon YYYY" } }
   One object per date: replace that date's object if it exists, keep the last 60 days, and only include counts you can actually measure (omit the rest - never guess). meetings = calendar events attended, emails = emails I sent, prompts = AI prompts I sent, commits = git commits I authored, docs = documents/attachments I produced or filed, tokens = AI tokens processed for me that day. Notes are counted by the plugin itself.
   AI usage ("tokens" per day and the "ai" block, last 45 days): read the usage logs of the AI tools on this computer - Claude Code (~/.claude/projects/**/*.jsonl: assistant messages have message.model and message.usage; count each message.id once; tokens = input + output + cache read + cache write) and Codex (~/.codex/sessions/**/*.jsonl: event_msg token_count -> last_token_usage.total_tokens, model from turn_context). Add other tools only if they keep local usage logs. Group by model (readable names) and by provider. Never include prompts, file names or costs.
   Code ("code" block, optional): if I use GitHub, count my commits in the last 52 weeks per week across my repositories (the gh CLI or the GitHub API), number of repos, and top 4 languages. Counts only - never repository names that are private.

C. Publish. If Caldera auto-publish is on (Settings -> Caldera -> Auto-publish every N hours), you are done. Otherwise ask me to run "Caldera: Publish my profile" from the command palette.

## 3. Privacy rules (these override everything above)
Everything public is on the open internet, can be copied forever, and can affect other people. Be very cautious. Never write any of these into anything public:
- Other people: no names, initials, handles, photos or descriptions that identify anyone I meet, work with, hire, date, advise or invest with. Say "a founder", "the team", "a friend" only when it adds nothing identifying - usually leave it out.
- Meetings: no meetings, calls, lunches, dinners, interviews or events - not their titles, times, dates, attendees, or that they happened with someone specific.
- Times and places: no times of day, schedules, travel, cities, venues, addresses, offices, home or "where I am".
- Secret or sensitive work: no unannounced, stealth, confidential or NDA projects, codenames, deals, fundraising, investors, acquisitions, valuations, hiring, firing or anything said in confidence.
- Things that can get someone in trouble: legal, medical, health, HR, money, salaries, debts, relationships, family, children, politics, religion.
- Contact details and links: no emails, phone numbers or links to private documents. No money amounts at all.
Describe work only by its public theme ("shipped a release", "wrote about design") and only name things I have already made public on my page (my own public projects, topics and links). If you are unsure, leave it out - an empty field is fine. Caldera also drops any journal line that looks sensitive before publishing.
Themes and topics: only use topics among the tags I allow-listed in Settings -> Caldera -> Public topics.
Also: never write to any other part of the vault, never change notes' privacy markings (caldera: public / friends), never touch .obsidian/plugins/caldera/data.json.

## 4. Check your work
After each run, tell me in two lines what you wrote for that day, and anything you skipped because it looked private.

## 5. When I ask you to change my page
My name, headline, photo, banner, links, properties, topics, which sections show and whether I'm listed in the directory all live in the frontmatter of "<ABSOLUTE PATH TO MY OBSIDIAN VAULT>/Caldera/profile.md". Edit that file (keep its format; the same privacy rules apply) and the page republishes itself within about a minute. Guide: https://caldera.social/guide.html

Already installed? In Obsidian, run Caldera: Copy AI agent setup prompt for a version pre-filled with your vault path, handle and topics.

Prefer to install by hand?

1 · Get the plugin

  1. No Obsidian yet? Download it free from obsidian.md, open it, and choose Create new vault.
  2. Download caldera-latest.zip.
  3. In your vault, open the hidden folder .obsidian/plugins/ and create a folder named caldera. On a Mac, Cmd+Shift+. shows hidden folders in Finder.
  4. Unzip into it: you should see main.js, manifest.json and styles.css.
  5. Restart Obsidian, then Settings → Community plugins → turn on Caldera.

Once listed in the community directory: Settings → Community plugins → Browse → search Caldera.

2 · Set it up

  1. Restart Obsidian. The Welcome to Caldera window asks for your name and a handle, publishes your page and opens it in your browser.
  2. Save your recovery key when it offers (Settings → Caldera → Export recovery key any time).
  3. Change anything later in the note Caldera/profile.md; see the Guide.
  4. Open the flame icon panel to add friends and give gravity.

Questions

Do I need Obsidian already?

No. Obsidian is a free notes app (obsidian.md) for Mac, Windows, Linux, iPhone and Android. The install prompt checks for it, installs it if you say yes, and creates your first vault (a folder of notes). Your page starts simple and fills in as you write.

Is it free?

Yes. The plugin, your profile and friends are free and open source. Optional paid features (like a hosted AI journal and custom domains) may come later.

Who can see my notes?

Only what you publish. Your vault is read on your device; Caldera publishes the sections you switch on and notes you mark caldera: public. Notes you share with a friend are encrypted so only that friend can read them.

What are help credits?

Points you earn by helping people with their asks. Everyone starts with 100. They have no cash value and can't be bought or sold.

Does it work on mobile?

Yes, the plugin runs on Obsidian desktop and mobile.

Can I host it myself?

Yes. Use Export profile to a vault folder to get a static site for any host, or run your own hub. The protocol is open.

How do I delete my profile?

In Obsidian, run Caldera: Delete my profile from the hub. Your page, friendships, asks, offers, gravity and credits on the hub are erased. Your vault is never touched.

What if I lose my device?

Your identity is a key in your vault's plugin settings. Export the recovery key when you set up, and import it on a new device.
