Using Claude Code, Codex or Cursor with Obsidian

Because an Obsidian vault is just a folder of Markdown files, AI coding agents like Claude Code, OpenAI Codex and Cursor can work in it directly: install plugins, edit notes, and run daily routines. Caldera ships copy-paste prompts built for this: one installs Obsidian (if needed) and the Caldera plugin, then has the agent write your daily journal and activity counts each morning under strict privacy rules, and never lets it touch your identity key.

Updated 2026-10-11 · by mjonesone, LLC

The three Caldera prompts

  • Setup (caldera.social/#install): install Obsidian and Caldera, then a daily journal + activity routine.
  • Make it richer (caldera.social/#richer): suggests public notes, topics, activity sources and a 14-day journal backfill, asking before anything goes public.
  • Change my profile (caldera.social/guide): describe a change in plain English; the agent edits Caldera/profile.md and the page republishes.

Safety rules built into the prompts

  • Privacy rules override everything: no names, clients, money, health, family or locations on public pages.
  • Anything that would become public needs your explicit yes.
  • The agent never reads or edits the plugin's key file, so your identity key never passes through the model.

Questions

Which AI agents work?

Any agent that can read and write files on your computer: Claude Code, OpenAI Codex, Cursor, and similar tools.

Can the AI run this daily?

Yes. The setup prompt describes a once-a-day routine you can schedule with your agent.

Does the AI see my private key?

No. The prompts forbid reading the plugin's data.json, and your identity is created by the plugin, not the AI.
