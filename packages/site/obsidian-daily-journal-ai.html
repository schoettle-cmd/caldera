An automatic daily journal in Obsidian, written by AI

You can have an AI agent write a short journal entry in Obsidian every morning: it reads yesterday's notes, calendar, sent email, commits and AI sessions, then adds a headline, focus, wins and themes to that day's daily note. With the Caldera plugin those entries become a flippable daily journal on your public profile, alongside an activity score, while the privacy rules keep names, clients and money out of anything public.

Updated 2026-10-11 · by mjonesone, LLC

What gets written

Four properties on each daily note (named YYYY-MM-DD.md): caldera_headline (one sentence), caldera_focus (2-4 items), caldera_wins (1-3 items) and caldera_themes (1-3 words). Daily counts (meetings, emails sent, AI prompts, commits, documents) go in Caldera/activity.json.

How to set it up

  1. Copy the setup prompt from caldera.social/#install into Claude Code, Codex or Cursor.
  2. After install, schedule the agent to run the daily routine each morning.
  3. Use the "make it richer" prompt to backfill the last 14 days.

Questions

Do I have to make the journal public?

No. The journal section has an on/off switch; the entries stay in your daily notes either way.

What if a day had nothing public to say?

The rules allow empty fields; the page shows the activity counts only.

Can I write entries myself?

Yes. The same four properties work whether you or an agent write them.
