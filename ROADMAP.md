# Roadmap

- **v0.1 (now):** living profile, preview/publish, friends, encrypted cards, asks/offers, credits (no cash value), gravity, leaderboards, CLI publisher, reference hub.
- **v0.2:** AI daily journal inside the plugin (bring your own key or local model; paid hosted option), friends-only profile layer, card update notifications, mobile polish, Obsidian community directory submission.
- **v0.3:** "Who in my network knows about X?" - query across friends' shared layers; matching; team/org directories.
- **v0.4:** paid tier (hosted AI, custom domains, analytics); real-money bounties on regulated rails (Stripe Connect escrow, platform fee). Any token only after legal review.
